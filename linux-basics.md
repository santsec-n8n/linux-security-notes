# Fundamentos do Linux

## 1. O que é Linux?

Linux é um sistema operacional de código aberto, muito utilizado em servidores, infraestrutura, computação em nuvem e segurança da informação.

## 2. Comandos básicos do terminal

| Comando | Função |
|---|---|
| `pwd` | Exibe o diretório atual |
| `ls` | Lista arquivos e diretórios |
| `ls -l` | Lista arquivos com detalhes |
| `cd` | Acessa outro diretório |
| `mkdir` | Cria um diretório |
| `touch` | Cria um arquivo vazio |
| `cat` | Exibe o conteúdo de um arquivo |
| `cp` | Copia arquivos |
| `mv` | Move ou renomeia arquivos |
| `rm` | Remove arquivos |

## 3. Exemplos práticos

### Verificar o diretório atual

```bash
pwd
```

### Listar arquivos

```bash
ls -la
```

### Criar um diretório

```bash
mkdir estudos-linux
```

### Criar um arquivo

```bash
touch anotacoes.txt
```

### Visualizar um arquivo

```bash
cat anotacoes.txt
```

## 4. Observações de segurança

- Tenha cuidado ao utilizar `rm`, pois ele remove arquivos.
- Antes de executar comandos desconhecidos, entenda sua finalidade.
- Evite executar comandos com privilégios administrativos sem necessidade.
- Sempre confira o diretório atual antes de modificar ou excluir arquivos.
